\section{2025年大事}
\label{sec:Grundlagen}
%
\textit{主要记录2025年我人生与生活中的一些大事、心态变化、学习进展等。}\\
\subsection{结婚}
2025年，我与我的爱人在山东老家举办婚礼。在家人、亲朋好友的帮助下，我们的婚礼成功举办。结婚意味着我们有了一个小家庭，为小家庭努力奋斗，给我带来了无穷的动力。
我坚信我们小家在杭州会越来越好！个人私生活部分不会过多介绍，这是我的性格决定的。
\subsection{买车}
买车其实在结婚之前，前面也有介绍，这辆车是广汽本田皓影插混。这辆车我前面多次发文介绍、并坦言她是我们小家的一个重要成员。这辆车是我与父亲亲自接回家、并按照山东习俗给她举行了一个庄重的仪式。
我驾驶她把我老婆从娘家接到我家、她全程参与我的婚礼、并载着我与老婆从山东老家平安到达杭州。她陪我走过杭州大街小巷、助力我事业发展。我会珍惜我人生的第一辆车。
\subsection{出国}
我与我老婆第一次出国，第一站选择了新加坡。
\subsection{中石油}
20225年，我选择了中石油，这是我的养老票、长期持有的股票。这是今年在股票市场上做出的一个正确决定。
\subsection{定投标普500}
2025年下半年开始了定投标普，这也是我要长期坚持的投资方式。定投标普500指数基金，长期持有、以后养老用。
\subsection{MacBook}
选择macbook pro是我本年做出的一个重要选择。现在看来这个选择无比正确，选择能够提升工作效率、提升工作质量的工具是十分必要的。
有些东西苹果做的确实好，比如显示屏、操作系统、生态系统等。我本人还需要写代码，MacBook对我工作帮助很大。
\subsection{iPhone }
基于macbook pro的良好表现，我给我老婆也选择了苹果手机。不基于情绪、而是基于理性选择工具，这也是我2025年人生态度的一个改变。

\section{工作总结}
\label{sec:ExpAufb}
%
\textit{2025年比2024年要好很多，我自身也提升很多。2025年的进展让我对2026年更有信心。}\\
\subsection{对自己无条件信任}
2025年，我完全对自己无条件信任。也许对旁人来讲，可能是傻、倔，我现在无条件信任自己、相信自己、看好自己，任何人的贬低都不会改变我对自己的信任、对未来的乐观。
\subsection{小初高全覆盖}
2025年，我实现了从小学、初中、高中的全覆盖教学。中考数学仍然是2025年的重点、奥数权重降低、高中权重适当提升。
成功组建了几个小组教学、多年级混班教学、线上线下结合教学等多种形式。
\subsection{余杭区深耕、主城区拓展}
2025年，我深耕余杭区，基本上实现了在余杭立足的目标。余杭区以小学为主、初中为辅。主城区以初中为主。
\subsection{走出浙江、面向全国}
2025年，加大了线上比例。线上教学占比达到60\%以上。学生覆盖全国多个省份，本年遇到了北京、上海、江苏、安徽、广东、海南、广西、重庆、山西、新疆、四川、湖北等地的家长，扩大了我的朋友圈。
\subsection{实现出海}
本年成功找到了几个海外的学生，主要是新加坡、日本、美国、马来西亚华人为主，大部分是短期学习。
\subsection{不搞预付费}
2025年，我坚持不搞预付费、仍然是课后支付课时费。与他人的合作目前除外，机构有机构的规则。虽然可能会造成一些损失、但是我仍然坚持不用课时费绑定学生与家长。
不管什么时候都可以停止与我的合作。
\subsection{不内耗}
家长与学生不跟你合作了，不要纠结、不要内耗，每个人都有自己的选择。就是此时的你不合适的、不要找自己的原因。下一个就好。如果后面家长继续找你、不带情绪，有时间还是继续合作。
\subsection{自媒体运营}
本年的重点依然在小红书平台，坚持原创。今年不再刻意讨好粉丝，不友善的言论直接删除、人身攻击的直接拉黑，哪怕粉丝也是如此。平台是我的情绪输出、一时所想，我不想有太多的辩论，也无需刻意解释。大家愿意看就看、不愿意看就划走。
\subsection{坚持做题}
今年的多次熬夜都是为了做题。基本上是初中压轴题、高中数学题为主。不断提升自己、耳熟能详、举一反三才能不断提升自己。
\subsection{坚持英语学习}
英语虽然不能做到每天学习，但是坚持数学原版阅读、英语vlog观看，首先保证阅读能力提升，听力与口语慢慢来。
\subsection{坚持写代码}
今年主要是对python、latex的学习与应用，本文就是基于latex完成。
\section{总结}
\label{sec:Ergebnisse}
马上就到了2号了，先简单做一个总结。
\subsection{有所得}
2025年是收获满满的一年，家庭、事业都有了很大的进展。坚信2026年一定会更好，自己做事情会遇到很多困难，但是这不要成为自己悲观的理由，想想自己的父母、自己的小家庭，人要勇于承担责任、勇于面对挑战、勇于克服困难。\newline
\subsection{要提升}
2026年坚持对自己高标准、高要求，尤其对自己教的学生耐心、负责。\newline
2026年坚持学习，不断提升自己，尤其是英语、编程、数学。\newline
2026年坚持自媒体运营，继续输出优质内容。\newline
\subsection{好心态}
有时候忙了来不及回复，这个也是正常，尽量做好就好.\newline
2026年坚持不内耗，别人不与你合作、不要纠结，自己尽心尽力就可以。\newline

2026年具体规划暂不罗列，本文更多是向家长与学生的一个简单汇报。也便于新的家长对我有个大体认识。\newline
期待与更多家长合作、与更多学生交流，我们共同进步。\newline
Happy New Year！
